# Jobware

My graduation project (B.Sc. Computer Information Systems, Al al-Bayt University, 2023): a job board built with plain PHP and MySQL.

## Features

- Register and log in, with an editable profile and profile photo
- Post, edit and browse jobs (city, salary, full/part time, validity)
- Apply for jobs and track each application's status
- Admin area

## Tech

PHP, MySQL, HTML, CSS, JavaScript

## Run it locally

1. Import `jobware.sql` into MySQL.
2. Update the database settings in `config/`.
3. Serve the folder with Apache/XAMPP and open `home/`.
